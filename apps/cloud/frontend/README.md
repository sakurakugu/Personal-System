# Vue 3 + TypeScript + Vite

该模板可帮助你开始使用 Vue 3 和 TypeScript 在 Vite 中进行开发。模板使用了 Vue 3 的 `<script setup>` SFC，查看 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) 了解更多。

更多关于推荐的工程配置和 IDE 支持，请查阅 [Vue 文档 TypeScript 指南](https://vuejs.org/guide/typescript/overview.html#project-setup)。
