# 桌面端开发任务清单

## 目标

这份清单用于跟踪桌面端与桌面小工具方案的实际落地进度。

当前原则：

- 不破坏现有 Web 和手机端登录
- 浏览器继续使用 `Cookie Session + CSRF`
- 原生桌面端使用 `Bearer 设备令牌`
- 主桌面端优先走 `Tauri + Vue`
- 桌面小工具后续走 `Qt`

## 当前实现备注

- `Tauri Store` 解决的是“脱离浏览器 `localStorage`，改走原生侧持久层”问题
- `Tauri Store` 不是系统密钥链，也不是 Stronghold
- 如果后续要防本机明文文件被读取，需要继续接系统密钥链或 Stronghold
