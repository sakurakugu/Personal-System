# Markdown 编辑器迁移验收清单

本文用于记录 Milkdown 编辑器迁移后的人工验收项。验收目标是确认编辑态可以正常同步 Markdown，预览和发布态继续走现有 `MarkdownRenderer`。

## 基础语法

- [x] 标题：输入或工具栏插入 `## 标题` 后，预览显示为二级标题。
- [x] 段落：连续输入普通文本，保存后内容仍为 Markdown 纯文本。
- [x] 加粗：工具栏加粗或输入 `**文本**`，预览显示加粗。
- [x] 斜体：工具栏斜体或输入 `*文本*`，预览显示斜体。
- [x] 行内代码：工具栏行内代码或输入 `` `code` ``，预览显示行内代码。
- [x] 链接：工具栏插入链接或输入 `[文本](https://example.com)`，预览可点击。 # 已补充链接输入规则，不再当普通代码片段处理
- [x] 图片：选择、粘贴或拖拽图片后，正文插入 `![说明](地址)`，文章图片面板同步出现记录。
- [x] 引用：工具栏引用或输入 `> 内容`，预览显示引用块。
- [x] 无序列表：工具栏列表或输入 `- 项目`，预览显示列表。
- [x] 有序列表：工具栏编号或输入 `1. 项目`，预览显示编号列表。
- [x] 表格：工具栏表格或输入 GFM 表格，预览显示表格。 # 支持 `|a|b|c|` + 回车生成 3 列 2 行表格
- [x] 代码块：工具栏代码块或输入 fenced code block，预览显示代码块。 # 支持输入 ``` 或 ```语言 后按回车生成代码块
- [x] 任务列表：输入 `- [ ] 待办` 和 `- [x] 完成`，预览显示任务列表。 # 左侧编辑态已显示任务复选框
- [x] 分割线：工具栏分割线或输入 `---`，预览显示横线。 # `---` 改为按回车后转换

## 增强语法

- [ ] KaTeX：输入行内或块级数学公式，编辑器源码模式不丢原文，预览正常渲染。 # 左边不支持，右边支持
- [x] 脚注：输入 `[^1]` 和脚注定义，编辑器源码模式不丢原文，预览正常渲染。 # 预览端启用脚注插件，并兼容 `[^1]:内容` 写法
- [x] Mermaid：输入 ` ```mermaid ` 代码块，编辑器源码模式不丢原文，预览正常渲染。 # 预览端会把 Mermaid 围栏转换为图表容器并触发增强渲染
- [x] 提示块：输入 `!!! note` 语法，编辑器源码模式不丢原文，预览正常渲染。 # 左边没显示，还是显示普通文本，但是右边的正确显示了
- [x] 折叠块：输入 `??? note` 语法，编辑器源码模式不丢原文，预览正常渲染。 # 同上
- [x] 标签页：输入 `=== "标签"` 语法，编辑器源码模式不丢原文，预览正常渲染。# 支持缩进内容的标签页组，并修复 Milkdown 序列化时添加 `\` 的问题

## 编辑流程

- [x] `Ctrl/Command + S` 保存当前文章。
- [x] `Ctrl/Command + Alt + E` 美化 Markdown 后保存。# 已避开 Edge 的 `Ctrl/Command + Shift + S` 冲突
- [x] `Ctrl/Command + Shift + Z` 在编辑器内执行重做。
- [x] 切换所见即所得和源码模式后，正文内容不变化。 # 已修复 `=== "pnpm"` 被序列化为 `\=== "pnpm"` 的问题
- [x] 切换预览、HTML、脑图，以及关闭、半边、全部布局后，编辑器内容不丢失。
- [x] 手机端编辑页工具栏可以横向滚动，正文和预览不互相遮挡。
- [ ] 暗色主题下工具栏、正文和预览可读。 # 目前左右两边样式还不一样，但是暗色可读，这个之后再说
